## 4. How we work (lean process, adopted by Jonathan on 2026-10-08)

A live app, so no skipped safety steps; but no tokens spent for nothing.
- **Keep:** pgTAP on grants, RLS and RPCs; auth/permission tests on edge functions; migration discipline; one review per task; a full review before each merge to `main`; full care on sensitive data (bank, SIN, signing, Loi 25).
- **Cut:** plan « As built » notes to a few lines (the code and tests are the detail); decisions log only for choices worth revisiting; Playwright for repeatable paths instead of screenshot walkthroughs (one manual walkthrough per batch for new screens); **2 parallel lanes**, not 3–4; **merge to `main` per batch** instead of one huge phase branch.

## 6. Decisions Jonathan made himself (don't revisit)

- **Motif display:** never a chip wall; never « Tous » without names. Category title on its own line, motifs in columns. Applies everywhere.
- **Catalogue:** approaches are removed. Motifs and clientèles come only from the 43 cliniquemana.com profiles, and Settings can still add and edit them.
- **Fiche PDF:** `@react-pdf/renderer` (PS Hub base), MANA brand (logo, wine `#9B1B3C`, mint, Raleway), v2 handoff (Approche, « Prochaine étape », clinic footer, optional pro contact). It shows public client fees only.
- **Addresses:** every address uses Google Places with a manual override. The label reads « Appartement ou bureau ».
- **Remuneration** (retention grid per profession by cumulative sessions; a 30-min session counts 0.5):
  - the grid suggests a tier; staff decide in the « Révision mensuelle »;
  - grid starts 2026-07-01;
  - Psychoéducation 60 min = 165 $;
  - Ateliers 25 %, Annulation tardive 30 %, Autres frais 15 %, the same for everyone;
  - « Ententes particulières » are per client: a fixed amount to the pro, and the client price is **required**;
  - « Taux particulier » re-flags at a new tier unless already at the top;
  - Nutritionniste has no grid for now;
  - « Coach certifié PNL » = « Coach professionnel·le certifié·e ».
- **Availability:** includes « Fin de journée ».
- **Titles:** shown in the form that matches each pro's gender.
- **Import:** add the 13 people missing from the website. Carole Forget is active.
- **Insurance default end date (P4-412):** an upload in January or February gets March 31 of the same year; March through December gets March 31 of the next year.
- **Document retention (P4-411):** never delete automatically for now. A rejected file is still soft-deleted, and staff may delete manually.
- **UI clarity:** « il faut toujours être clair ». Plain-word statuses, values on buttons, French everywhere, no cryptic symbols.

## 7. Rules (strict)

- **Outward actions need Jonathan's explicit go-ahead each time:** pushing `main`, opening PRs, mutating staging, running migrations or resets on staging, deploying functions, setting secrets or Auth settings. Never use MCP `apply_migration` or the dashboard. Never enter secrets; Jonathan pastes them himself.
- **Real people's data** (names, rates, emails, bios) never goes in the repo.
- **Read-only:** PS Hub (`../NEW PS Hub`, the tiebreaker for patterns) and `_legacy/`. Never touch PS Hub's 543xx stack.
- **Git:** commit explicit paths only. Never `git commit -a` where an agent works; no bare `git stash`. Commits end with the `Co-Authored-By` line from the session's attribution guidance.
- **iCloud duplicates:** the repo sits in iCloud-synced `~/Documents`, which spawns « name 2.ext » copies in worktrees and `.git`. Check with `git status --porcelain | grep ' 2\.'`. Verify a copy matches a committed blob before deleting it, and never commit one. Recommend that Jonathan move the repo out of iCloud.
- **Process:** see « How we work » at the top (lean, adopted 2026-10-08). Features Jonathan asks for are pulled forward.
- **DB conventions:**
  - closed grants; RLS via `private.current_permission_keys()`; `security definer` with `search_path=''`;
  - French P0001 errors carrying a HINT, routed to form fields;
  - soft delete; audit triggers with redaction;
  - migration timestamps never end in `00` seconds; unreleased migrations are edited in place;
  - in pgTAP, never call a function the switched role is refused (supautils segfaults): use `function_privs_are`.
- **Dates:** clinic-timezone utilities only; `formatDateOnly*` for date-only fields (see CLAUDE.md).
